## Run Locally

Clone the project

```bash
  git clone https://github.com/Umm12many/GoogleTranslatedFinishingTouches
```

Go to the project directory

```bash
  cd GoogleTranslatedFinishingTouches
```
Then put the Mod folder in your emulators mods folder and rename it to whatever you want.
